# Reportes de Rauch ERP

Este directorio es el historial permanente de pruebas, revisiones y decisiones operativas del proyecto.

## Estructura

- `qa/`: resultados fechados de pruebas funcionales, automatizadas y manuales.
- `templates/`: plantillas reutilizables para nuevas validaciones.

## Convenciones

- Nombre: `YYYY-MM-DD-descripcion.md`.
- Registrar ambiente, alcance, datos QA creados, resultados, defectos y pendientes.
- No guardar contraseñas, tokens, cadenas de conexión ni datos personales reales.
- Adjuntar activos reproducibles en `test-assets/` y enlazarlos desde el reporte.
