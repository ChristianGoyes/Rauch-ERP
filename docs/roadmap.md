# Recomendaciones y próximos pasos

1. **Prioridad inmediata:** caja por turno (apertura, ingresos, retiros y cierre) y medios de pago conciliables.
2. **Facturación:** numeración consecutiva, clientes, impuestos y preparación para facturación electrónica DIAN.
3. **Inventario:** mínimos por producto, alertas, devoluciones, conteos físicos y transferencias entre bodegas.
4. **Ventas:** descuentos autorizados, anulaciones con reverso de stock y comprobante imprimible.
5. **Trazabilidad:** auditoría de cambios de precios, usuarios, permisos y productos.
6. **Operación:** copias de seguridad automáticas, almacenamiento externo de imágenes y monitoreo de errores.
7. **Calidad:** pruebas funcionales para compras→stock→venta→kardex y pruebas específicas de permisos por perfil.

Organization queda deliberadamente como configuración secundaria mientras exista una sola empresa y un solo local. El contexto los selecciona automáticamente, pero se conserva el diseño multiempresa para no bloquear el crecimiento futuro.

VAG Rounded es una tipografía comercial. La interfaz la usa como primera preferencia si está instalada o licenciada; Nunito actúa como alternativa abierta hasta que se agregue un archivo de fuente con derechos de uso.
